# Chord Companion - Chrome Extension

This extension displays synced lyrics and chords for Spotify and YouTube in a side panel.

## Installation

1.  Open **Google Chrome**.
2.  Navigate to `chrome://extensions`.
3.  Enable **Developer mode** (toggle in the top-right corner).
4.  Click **Load unpacked**.
5.  Select this folder: `/Users/drost/workspace/obsidian/Whocares/extension`.

## Usage

1.  **Pin the Extension:** Click the puzzle piece icon in Chrome and pin "Chord Companion".
2.  **Open Music:** Go to [YouTube](https://youtube.com) or [Spotify](https://open.spotify.com) and play a song.
3.  **Open Panel:** Click the extension icon to open the Side Panel.
4.  **Enjoy:** The lyrics and chords should load automatically!

## Features

*   **Lyrics:** Auto-fetched from LRCLIB (synced).
*   **Chords:** Auto-scrolling chord sheet.
*   **Edit Mode:** If chords are missing or wrong, click "Edit", paste your own, and click "Save". They will be saved for next time!
